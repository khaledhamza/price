GitHub access

Saving updates the price file in the site's GitHub repository, so it needs a GitHub token with write access to it. The token stays in this browser and is only sent to GitHub.

  1. Open GitHub → New fine-grained token.
  2. Repository access: Only select repositories → price.
  3. Permissions → Repository → Contents: Read and write. Generate it and paste it here.

Totals

PAR = RETAIL × PAR % + admin fee. COST = RETAIL × COST %.

Commission

Sold below the cutoff: that % of the sold price. From the cutoff up to PAR: the middle % of the sold price. Above PAR: the middle % of PAR (the PAR above, admin fee included) plus the share of every dollar above PAR. Financed jobs have the finance % taken off the sold price first.
